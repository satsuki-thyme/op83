物語のコンセプトは構図だ。

- もしカッパが砂漠の横断に挑戦したら
- もし疎遠になっている父親と二人きりで長距離ドライブすることになったら

困難が予想されるものがいい。「カッパと砂漠」「疎遠の父親と息子」という構図が、対比が、物語を含んでいる。こういうものを考えていく。

# 前提

コンセプトは僕にとって最初に決めることではないらしい。

しばしばテーマと同時期に設定するものだと思う。作品の核になる部分だ。コンセプトが面白みを含んでいなければ作品は活きてこない。最初に考えるにふさわしい重要性をしている。

だけど僕にとって重要なことはまずモチーフだ。モチーフは――一般的な創作上の理解ではないと思うけど――物語の環境のようなものだ。

- 新聞記者が活躍する話
- 冒険者の話

抽象的な意味での「舞台」とも言える。ここのところを少し詰めて決めておくのが僕にとって好ましい。

別の思考ノートで考えたものがある。タイトル「思考ノート - 小説作品の企画と作り始め（op83）」で公開している。ここからエッセンスを取り出すと次のようになる。

- モチーフ  
  魔法屋
- 主人公  
  ドラゴンとエルフのハーフ。子ができないはずの交配にできた子。どちらの特徴も表面的には相殺して現れていない。なので普通の人に見える。年齢5万3678歳。外見は20歳の男性。見目麗し。細マッチョ。性格は穏やか。好奇心旺盛。今は世界中を何度も旅した果に王都で魔法屋をしている。
- テーマ  
  自由に生きる。
- 苦境  
  自由に生きようとすることで生まれる対立や葛藤。

これを前提としてコンセプトを考える。

# スタート地点

例によって僕の物語の主人公は最強の存在だ。バトルを主体としては話が面白くならない。だから人間関係で苦労することになっている。前述に「苦境」として設定したものがそれだ。

コンセプトでは人間関係についての構図を考える。

# 捉え直し

ハイコンテクストを狙いたい。

ハイコンテクストなコンセプトは短い文で強い物語性を感じさせられるコンセプトだ。そういうものは訴えかける力が強い。前述のカッパや疎遠の父親はハイコンテクストと言えるだろう。だけどハイコンテクストは難しい。僕は前提条件があるからなおさらだ。

ハイコンテクストは奇妙なものになりやすいと感じている。極端な状況設定で、どこかマンガ的なデフォルメを感じる。シリアスな路線には向かない気もするけど改めて考えてみると、例えば映画「タイタニック」だとかゲーム「バイオハザード」はハイコンテクストだと思うけど変なデフォルメは感じない。ちょっと勘違いしている節がある。

そのあたりを補正しつつやっていこうか。

# ストーリーの核としては

主人公は古くから王都に店を出している。王朝が変わって遷都される前、以前の王都のころから店を持っている。魔法技術の高さから王家とのつながりも深い。そこに葛藤・対立を持ち込めないだろうか。

王の代替わりで関係に違いが出るのか。王子との関係があるかもしれない。王太子は他の魔法制作者とつながりがあり主人公を排除したいかもしれない。王に影響力のある主人公を邪魔に感じる者がいるだろうか。

王家とのつながりはなんとなく思いついたんだけど、作品のスケール感を表現するにはちょうどいい気がする。

この線でいこうとすると王太子が魔法制作者にだまされていると都合がいいかもしれない。それで主人公を排除しようとしている。魔法制作者は何かの間者なんだろう。なんの間者か。他国、魔族、魔法結社。どこの間者かは選ぶとして、いろいろな立場から王家に干渉しようとしていると複雑さが出て面白いだろうか。

# ひらめきと読み

コンセプトを使ったタイトルを思いついた「

5万年生きた賢者、王国の乗っ取りを糾弾される――その気ならとっくに乗っ取ってます

」とかどうだろう。流行のWeb小説は主人公が最初に落とされるもぜんぜん平気でむしろそっちが困りませんか、的なやつも多い。その系譜に寄り添ってみた。

王家サイドが糾弾するのではなく王国を乗っ取りたい誰かが主人公を邪魔と見て糾弾するんだけど。でも流行っているのは復讐心を煽られるのが面白いのであって、害をなそうとする人がいるだけじゃ面白みにつながらないのかな。そうると別のことを考えないと。

# 自分の方向性を定めた

ここで前の前のセクション「ストーリーの核としては」に戻るんだけど、そんな複雑な話にしたらプロットなしでできないじゃん！　シンプルにしないと。しかも方向性だけ示すみたいなことじゃないとけっきょくプロットが出来上がってしまう可能性がある。これは要注意だ。

方向性だけで引きつけるようなものはミニマルな仕掛けだと思う。小説「ゴブリンスレイヤー」はそういうタイプじゃないだろうか。Web小説界隈では最弱という認識のあるゴブリンに特化した冒険者は方向性が飛び抜けている。オリエンタルランドだ。そういう感じのものを想像したらいい。

強いこだわりなのかなぁ。あまり好きなタイプじゃないんだけど。僕は実際の人生において「執着 = 強いこだわり」を減らすのが目標だから。まぁ執着を減らすことに執着しているのかもしれないけど。うーん、でもそんなに執着心はないかなぁ。ダメだなぁ。ダメなのかなぁ。

いや、閑話休題。

バランスにこだわるとか、事実にこだわるとか。それとも女性が好き、というのはありがちだなぁ。ありありだ。他には……やっぱりこの方向性は違うのかなぁ。

だいたい度を超したものはコミカルに見えやすいし。

いや、でも可能性がないわけじゃない。探っていきたい。何にこだわるか、だ。

それで、ふと前述したゲーム「バイオハザード」について思った。実はよく知らない。ゾンビだな、くらいの印象だ。だからゾンビにこだわっているのかと思っていた。ChatGPTにたずねたところ、それより「人間や生物が異質なものに変わる恐怖にこだわるシリーズ」と答えが返ってきた。これはヒントになるかもしれない。

僕は今まで小説「ゴブリンスレイヤー」をゴブリンにこだわった作品だと思っていた。でも違う。「ゴブリンに執着する構造」にこだわっているんじゃないか。方向性というならそういう解釈をするほうが正しい気がする。

だから例えば「苦難を乗り越えて勝利する構造」にこだわればよくある物語が生まれる。これだけ抽象的に表せばゴブリンスレイヤーもそのくくりに入るだろう。

もう少し絞ったほうがいいかもしれない。

ChatGPTとの[対話](https://chatgpt.com/share/6ae15b77-ee24-83ec-b08e-9ce8b6960740)の末に「読者にどんな面白みを与え続けたいか、からスタートするといい」という話になった。目的の面白さを持つ作品を見つけて作品の要素を他の要素にすげ替えるという方向性だ。十分に抽象的なレベルで行えばパクりには見えないしマネているとも言いがたい。

# 読者に与えたい面白さ

これについては元々決まっている。今の僕が追い続けるテーマがある――

大小の課題に挑んで解決し続けることが人生の満足である。

――というものだ。つまり今回のケースに当てはめれば「大小の課題に挑んで解決し続ける」とできる。このとき課題は課題としてふさわしいものを選ぶ必要がある。

昔ながらの作品で見かけるものに「奇跡的な力の発揮で解決する」ものがある。これは僕にとって課題としてふさわしくない。

昨今の流れでは「余裕で解決する」ものが多い。これも僕にとって課題としてふさわしくない。

僕が欲しいのは「解決するに十分な力を持っているが解決には困難がともなう」という程度だ。それを武力では圧倒的な強者の主人公にやらせるのだ。だからいつも武力ではない問題を用意する必要がある。

しかしこのテーマは「程度の問題」を表しているような気がしてきた。課題を解決するのはほとんどの作品に共通する部分だろう。そういう意味では今回求めているものとは合致しない気がしてきた。

# 読者に伝えたい面白さ 2

改めて考えてみるとどうなんだろう。そもそも僕が読みたいと思うような作品を作りたい。実際に自作品を読むかは別として。

それで僕が求めているのは主人公が最強であることだ。バトルでは相手の攻撃を十分に味わってからねじ伏せるというのが好ましい。ここは捨てられない部分だった。

でも最低条件としたい。そのうえで何が描かれるといいのか。という話になると大小の課題に挑んで解決する、となってしまう。つまり最強の主人公がバトルで無双しつつそのほかの課題を解決していく状態そのものが好ましいのだ。

それ以外となると細かな話になる。シリアスな展開だとか、女の子にモテたいとか、物語の核心には関係がない。

そもそも僕は伝えたいことがあるわけじゃなかった。好みがあるだけだ。その好みも限定的でない。それに考えてみると限定的でないどころか物語一般を好んでいるだけだ。それなのに好みに合う作品を見つけるのに苦労するというのは作風に対して注文が多いんだと思う。物語がどんどん進む話が好きだとか、課題は簡単すぎず難しすぎずだとか。

なので問題は「読者に伝える面白さとして何を選ぶのか」となる。

# どんな面白さを伝えるか

僕自身はわりとなんでもいいので戦略的に選んで持ってくることにしよう。それでChatGPTと対話したんだけど話が流れていって思うような結果は得られなかった。残念。自分で考えろということか。

Web小説の異世界ファンタジーでは自己効力感が得られるものや復讐心が満足させられるものがウケているはずだ。自己効力感は好ましいところかな。作品全体を復習の話にはしたくないかな。

それにしても考えているうちにどうでもいい気分になってきた。というかさっき午前3時の時点でインスタントラーメンを食べて満足しており、今の僕は満たされているから欲求が少ない。小説制作に向ける思いも減退しているんじゃないだろうか。ここで「どうでもいい」という投げやりな判断は禁物だ。コンセプトはウケるために重要だからだ。初心に返って考えていこう。

「この作品によってあなたはこんな面白さが得られますよ」というやつだ。ある程度具体的に。

主人公が欲求を前進的に満たすのが書きたいんだよな。つまり問題に対処するのではなく、欲求を満足させるために課題を解決するものだ。しかし発生した問題を解決して正常に戻したいという欲求のほうが強いと思うので、構造としてはそういう路線にならざるをえない部分がある。

それでどうしようかな。

# 唐突にコンセプトが生まれる

なんとなく思いついたんだけど――

心をボロボロにされたヒロインを助けて拾って復活させつつ主人公は大きな問題を可決する。（key point）

――という話がいいんじゃないかな、と。内々のコンセプトとしてはそんな感じで。

伝える面白さとしては「不遇から復活し躍進する開けた展望」というウケ要素をヒロインにやってもらって、主人公は「救う満足感」「導く優越感」「問題解決の自己効力感」というウケ要素を狙っていく。欲張りに見えるけどこのくらいレパートリーを積んでおかないとネタ切れしそう。（key point）

外向けのコンセプトを長文タイトルにして――

敗北エルフを拾ったので復活させる　―世界支配すら可能な5万年の賢者は救済のかたわら事件を堪能する―（key point）

――くらいに。
