物語のコンセプトは構図だ。

- もしカッパが砂漠の横断に挑戦したら
- もし疎遠になっている父親と二人きりで長距離ドライブすることになったら

困難が予想されるものがいい。「カッパと砂漠」「疎遠の父親と息子」という構図が、対比が、物語を含んでいる。こういうものを考えていく。

# 前提

コンセプトは僕にとって最初に決めることではないらしい。

しばしばテーマと同時期に設定するものだと思う。作品の核になる部分だ。コンセプトが面白みを含んでいなければ作品は活きてこない。最初に考えるにふさわしい重要性をしている。

だけど僕にとって重要なことはまずモチーフだ。モチーフは――一般的な創作上の理解ではないと思うけど――物語の環境のようなものだ。

- 新聞記者が活躍する話
- 冒険者の話

抽象的な意味での「舞台」とも言える。ここのところを少し詰めて決めておくのが僕にとって好ましい。

別の思考ノートで考えたものがある。タイトル「思考ノート - 小説作品の企画と作り始め（op83）」で公開している。ここからエッセンスを取り出すと次のようになる。

- モチーフ  
  魔法屋
- 主人公  
  ドラゴンとエルフのハーフ。子ができないはずの交配にできた子。どちらの特徴も表面的には相殺して現れていない。なので普通の人に見える。年齢5万3678歳。外見は20歳の男性。見目麗し。細マッチョ。性格は穏やか。好奇心旺盛。今は世界中を何度も旅した果に王都で魔法屋をしている。
- テーマ  
  自由に生きる。
- 苦境  
  自由に生きようとすることで生まれる対立や葛藤。

これを前提としてコンセプトを考える。

# スタート地点

例によって僕の物語の主人公は最強の存在だ。バトルを主体としては話が面白くならない。だから人間関係で苦労することになっている。前述に「苦境」として設定したものがそれだ。

コンセプトでは人間関係についての構図を考える。

# 捉え直し

ハイコンテクストを狙いたい。

ハイコンテクストは短い文で強い物語性を感じるコンセプトだ。そういうものは訴えかける力が強い。前述のカッパや疎遠の父親はハイコンテクストと言えるだろう。だけどハイコンテクストは難しい。僕は前提条件があるからなおさらだ。

ハイコンテクストは奇妙なものになりやすいと感じている。極端な状況設定で、どこかマンガ的なデフォルメを感じる。シリアスな路線には向かない気もするけど改めて考えてみると、例えば映画「タイタニック」だとかゲーム「バイオハザード」がそうだとは感じない。ちょっと勘違いしている節がある。

そのあたりを補正しつつやっていこうか。

# ストーリーの核としては

主人公は古くから王都に店を出している。王朝が変わって遷都される前、以前の王都のころから店を持っている。魔法技術の高さから王家とのつながりも深い。そこに葛藤・対立を持ち込めないだろうか。

王の代替わりで関係に違いが出るのか。王子との関係があるかもしれない。王太子は他の魔法制作者とつながりがあり主人公を排除したいかもしれない。王に影響力のある主人公を邪魔に感じる者がいるだろうか。

王家とのつながりはなんとなく思いついたんだけど、作品のスケール感を表現するにはちょうどいい気がする。

この線でいこうとすると王太子が魔法制作者にだまされていると都合がいいかもしれない。それで主人公を排除しようとしている。魔法制作者は何かの間者なんだろう。なんの間者か。他国、魔族、魔法結社。どこの間者かは選ぶとして、いろいろな立場から王家に干渉しようとしていると複雑さが出て面白いだろうか。

# ひらめきと読み

コンセプトを使ったタイトルを思いついた「

5万年生きた賢者、王国の乗っ取りを糾弾される――その気ならとっくに乗っ取ってます

」とかどうだろう。流行のWeb小説は主人公が最初に落とされるもぜんぜん平気でむしろそっちが困りませんか、的なやつが多い。その系譜に寄り添ってみた。

王家サイドが糾弾するのではなく王国を乗っ取りたい誰かが主人公を邪魔と見て糾弾するんだけど。でも流行っているのは復讐心を煽られるのが面白いのであって、害をなそうとする人がいるだけじゃ面白みにつながらないのかな。そうると別のことを考えないと。

# あ

ここで前の前のセクション「ストーリーの核としては」に戻るんだけど、そんな複雑な話にしたらプロットなしでできないじゃん！　シンプルにしないと。しかも方向性だけ示すみたいなことじゃないとけっきょくプロットが出来上がってしまう可能性がある。これは要注意だ。

方向性だけで引きつけるようなものはミニマルな仕掛けだと思う。小説「ゴブリンスレイヤー」はそういうタイプじゃないだろうか。Web小説界隈では最弱という認識のあるゴブリンに特化した冒険者は方向性が飛び抜けている。オリエンタルランドだ。そういう感じのものを想像したらいい。

強いこだわりなのかなぁ。あまり好きなタイプじゃないんだけど。実際の人生において執着を減らすのが目標だから。まぁ執着を減らすことに執着しているのかもしれないけど。うーん、でもそんなに執着心はないかなぁ。ダメだなぁ。ダメなのかなぁ。

いや、閑話休題。

バランスにこだわるとか、事実にこだわるとか。女性が好きというのはありがちだなぁ。ありありだ。他には……やっぱりこの方向性は違うのかなぁ。

だいたい度を超したものはコミカルに見えやすいし。
